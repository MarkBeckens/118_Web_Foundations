# Week 2 — Add Basic CSS Styling (Iteration 1)

## What I Intended to Do (Plan)

This week’s task was to add basic CSS styling to the existing SES website created in Week 1. 
The assignment required creating a single external CSS file, linking it to all pages, and 
applying simple styling to improve readability and layout. The focus was on making visible 
changes and understanding how CSS affects HTML structure.

My specific goals for Week 2 were:

- Create one external CSS file (`style.css`)
- Link the CSS file to all three HTML pages
- Apply basic styling to:
  - Text (font, size, color)
  - Background colors
  - Spacing (margin and padding)
- Ensure the text is readable and the layout is not cluttered
- Make simple, visible improvements without worrying about perfect design

The expectation for this week was that the styling might be simple or inconsistent, and that 
was acceptable. The main goal was connecting CSS to HTML and seeing how styles apply.


## What I Completed

This week I successfully:

- Created a single external CSS file (`style.css`)
- Linked the stylesheet to all pages using the `<link>` tag in the `<head>`
- Applied basic styling including:
  - Changing fonts and text colors
  - Adjusting font sizes for headings and paragraphs
  - Adding background colors to sections and the navigation bar
  - Adding margins and padding to improve spacing
- Improved readability across all pages
- Reduced the “giant image” problem from Week 1 by adding spacing and basic layout structure

The website now looks noticeably better than Week 1, even though the styling is still simple.


## Reflection

I realized that duplicating the same images inside each weekly folder was inefficient and caused unnecessary path changes. 
Since the assets are reused every week and do not change, I moved them to a single top‑level assets directory. 
This keeps the project cleaner, prevents broken image paths, and avoids repeating the same files 16 times.

Week 2 went smoothly overall. Linking the CSS file to all pages was straightforward, and once 
the stylesheet was connected, I could immediately see changes as I experimented with different 
styles. Adjusting fonts, colors, and spacing made the pages much easier to read.

The biggest improvement was fixing the layout issues caused by the large images in Week 1. 
Even basic margins and padding made the content feel more organized. I also learned how small 
CSS changes can dramatically improve readability.

Some styling still feels inconsistent, but the assignment said that was expected for this 
iteration. The important part was understanding how CSS connects to HTML and how styles apply 
across multiple pages.

Overall, Week 2 was a solid step forward. The site is still simple, but it finally looks like 
a real website instead of raw HTML.
