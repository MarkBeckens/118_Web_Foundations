# Week 5 Assignment Dom Interaction & Events

## Reflection and explaination

This week I connected JavaScript to my web pages and added interactivity. I used a separate JavaScript file and added click events to the table headers on the Team page. When a user clicks a header, the table sorts the rows and updates the arrow to show the sort direction.


Reflection:  
Connecting JavaScript to my webpage helped me understand how websites react to user actions. Instead of being static, the page becomes dynamic and changes based on events and logic. It made the relationship between HTML structure and JavaScript behavior much clearer.
