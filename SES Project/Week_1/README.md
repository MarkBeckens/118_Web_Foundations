# Week 1 — Initial Website Version

## What I Intended to Do (Plan)

The goal for Week 1 was to create the initial version of my SES website using only HTML. 
According to the assignment requirements, I needed to build at least three pages (Home, 
About, and a Topic page). Each page had to include headings, paragraphs, and at least one 
list. I also needed to add navigation links between all pages and use basic semantic 
structure.

My specific intentions for Week 1 were:

- Create three HTML pages:
  - **Home page**
  - **About page**
  - **Team page**
- Include headings (h1, h2), paragraphs, and at least one list on each page.
- Add navigation links so all pages connect to each other.
- Use basic semantic HTML structure (headings, paragraphs, lists, nav).
- Insert the SES header or body image depending on the page.
- Focus on “getting something working,” even if imperfect, as the assignment states.

This week is meant to establish the foundation that future weeks will build on.


## What I Completed

I successfully created the required three pages:

- **index.html** — Home page with headings, a paragraph, a list, and navigation.
- **about.html** — About page with headings, a paragraph describing SES, a list, and navigation.
- **team.html** — Topic page with headings, a paragraph, navigation, and a full unordered list 
  of all 30 MLB teams.

All pages include:

- Headings (h1, h2)
- Paragraphs
- At least one list
- Navigation links connecting all pages
- Basic semantic structure

This version is intentionally simple and unstyled, matching the Week 1 expectations.


## Reflection

This version is imperfect, which is exactly what the assignment said to expect. The biggest 
challenge was how large the images appeared without CSS. 

Building the pages themselves was straightforward. Adding navigation helped me understand how 
HTML pages connect, and using headings, paragraphs, and lists reinforced the basics of semantic 
structure. The lack of CSS made everything look plain and unorganized, which highlights why 
Week 2 will focus on styling and layout improvements.

Overall, Week 1 gave me a working foundation. The pages connect, the structure is correct, and 
the assignment requirements were met. I’m ready to move into Week 2 to begin improving the 
appearance and readability of the site.


## What I Want to Improve Next Week

- Resize and properly scale the header and body images.
- Add CSS to improve layout, spacing, and readability.
- Style the navigation bar.
- Make the pages more visually organized.
- Begin transitioning from “functional” to “polished.”
